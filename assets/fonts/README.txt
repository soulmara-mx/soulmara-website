SOULMARA — brand font slot
===========================

Drop your licensed "Milk and Honey" web font files here:

    milk-and-honey.woff2   (preferred)
    milk-and-honey.woff    (fallback)

The CSS (@font-face in css/styles.css) already points at these
filenames, so once they're here the whole site switches from the
temporary Fredoka fallback to your real brand font automatically.

To convert a .ttf/.otf you own into .woff2/.woff, use any font
converter (e.g. an offline tool or Font Squirrel's webfont generator),
keeping the family name "Milk and Honey".
